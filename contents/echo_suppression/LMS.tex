\section{LMS (Least Mean Squares)}

We can avoid having to generate the impulses if we are able to
construct a mathematical model of our acoustic environment's response
to those impulses (or to any other audio signal, such as the one output
by our speakers). For the sake of simplicity, we will assume that this
model is a FIR filter and attempt to estimate its coefficients.

The LMS algorithm can find $\mathbf{h}$ adaptively. For this, we model
\begin{equation}
  \tilde{\mathbf{s}} \approx \hat{\mathbf{s}} \triangleq \mathbf{h} * \mathbf{s},
\end{equation}and define that the error (what we should send through the network) is
\begin{equation}
  \mathbf{e}=\mathbf{m}-\hat{\mathbf{s}}.
  \label{eq:LMS_error}
\end{equation}
So, for each input (audio) sample, we have
\begin{equation}
  \hat{\mathbf{s}} = \mathbf{s}^\top\mathbf{h} = \mathbf{h}^\top\mathbf{s}.
\end{equation}
After substituting this result in \eqref{eq:LMS_error}) we obtain that
\begin{equation}
  \mathbf{e}=\mathbf{m} - \mathbf{h}^\top\mathbf{s}.
\end{equation}
Now, we compute
\begin{equation}
  \mathbf{e}^2 = \mathbf{m}^2 - 2\mathbf{m}\mathbf{s}^\top\mathbf{h} + \mathbf{h}^\top\mathbf{s}\mathbf{s}^\top\mathbf{h}.
\end{equation}
Thus, the Mean Squared Error is
\begin{equation}
  \begin{split}
  \text{MSE} = \xi = \mathbb{E}[\mathbf{e}^2] = \mathbb{E}[\mathbf{m}^2] - 2\mathbb{E}[\mathbf{m}\mathbf{s}^\top]\mathbf{h} + \mathbf{h}^\top\mathbb{E}[\mathbf{s}\mathbf{s}^\top]\mathbf{h} & = \mathbb{E}[\mathbf{e}^2] = \mathbb{E}[\mathbf{m}^2] - 2P\mathbf{h} + \mathbf{h}^\top R\mathbf{h}.
    \end{split}
\end{equation}
As can be seen, the MSE is a cuadratic function of $\mathbf{h}$, i.e.,
a (in general hyper-) paraboloid in which we can find the minimum (the
optimal values for $\mathbf{h}$) using the
\href{https://en.wikipedia.org/wiki/Method_of_steepest_descent}{Steepest
  Decent Algorithm}. Ideally, we should compute (iteratively)
\begin{equation}
  \mathbf{h}\leftarrow\mathbf{h}+\mu(-\nabla),
\end{equation}
where $\mu>0$ is the learning rate, and the (ideal) gradient is
\begin{equation}
  \nabla = \frac{\partial\xi}{\partial\mathbf{h}} =
  \begin{bmatrix}
    \frac{\partial\xi}{\mathbf{h}_0} \\
    \frac{\partial\xi}{\mathbf{h}_1} \\
    \vdots \\
    \frac{\partial\xi}{\mathbf{h}_{L-1}}
  \end{bmatrix}.
\end{equation}
Unfortunatelly, we don't have $\xi$, but we can approximate it using
the instanteneous error (see \eqref{eq:LMS_error}). Thus
\begin{equation}
  \hat{\nabla} = \frac{\partial\mathbf{e}^2}{\partial\mathbf{h}} = 2\mathbf{e}\frac{\partial\xi}{\partial\mathbf{h}} = 2\mathbf{e}(-\mathbf{s}),
\end{equation}
obtaining finally that
\begin{eqnarray}
  \mathbf{e} \leftarrow \mathbf{m} - \mathbf{s}^\top\mathbf{h}, && \\
  \mathbf{h} \leftarrow \mathbf{h} + 2\mu\mathbf{e}\mathbf{s}. &&
\end{eqnarray}

\subsection{Normalized LMS}
Stability requires $0 < \mu < 2/(L · \sigma^2(s))$, so the step size
depends on the input power. For speech, whose level varies enormously,
this is a problem. So use NLMS, which normalizes by the input energy
\begin{equation}
  \mathbf{h} \leftarrow \mathbf{h} + \frac{2\mu\mathbf{e}\mathbf{s}}{\epsilon+\mathbf{s}^\top\mathbf{s}}.
\end{equation}

\subsection{Choosing $L$}
$L$ must cover the echo path
\begin{equation}
  L \approx f_sT,
\end{equation}
where $T$ is the echo tail (the acoustic delay plus reverberation). At
44.1 kHz and 50–100 ms of latency, that’s about 2000-4500 taps. Also,
any system latency (audio buffers, chunk size) between playing
$\mathbf{s}$ and recording it shows up as leading zeros in
$\mathbf{h}$. Remember that you must update the filter coefficients for
every input sample!

\subsection{Python example}
\begin{lstlisting}[language=Python]
import numpy as np

class NLMS:
    def __init__(self, L=2048, mu=0.5, eps=1e-6):
        self.L, self.mu, self.eps = L, mu, eps
        self.w = np.zeros(L)
        self.hist = np.zeros(L - 1)          # last L-1 reference samples

    def process(self, x, d):
        """x: reference chunk (played), d: microphone chunk. Float arrays, same length."""
        buf = np.concatenate((self.hist, x))
        e = np.empty_like(d)
        for n in range(len(d)):
            u = buf[n:n + self.L][::-1]      # [x(n), x(n-1), ..., x(n-L+1)]
            e[n] = d[n] - self.w @ u
            self.w += (self.mu * e[n] / (self.eps + u @ u)) * u
        self.hist = buf[-(self.L - 1):]
        return e
\end{lstlisting}

corrupts the adaptation (the filter “diverges”). So, it is necessary

The LMS (Least Mean Squares) algorithm is an algorithm designed to
minimize the mean square error of a target function.


LMS is adaptive,
which means that it suitable when there are near-end acoustic
variations. In the previous section we have computed the near-end
audioset impulse response using the frequency domain. In this case, we
will use the time domain, i.e.,
\begin{equation}
  \hat{\mathbf e}[t] = \sum_{k=0}^{N-1}{\mathbf h}_k^{(t)}{\mathbf s}[t-k]
\end{equation}
where ${\mathbf h}$ is the near-end impulse response and $N$ is the
length of the LMS filter.

LMS minimizes the energy of the residue signal
\begin{equation}
  r[t] = {\mathbf m}[t] - {\mathbf n}[t-d]
\end{equation}
(the difference between the signal captured by the mic and the signal
generated by the near-end user) that ideally, after a delay of $d$
samples (an input parameter of this technique) should be the echo
signal. More concretely, LMS minimizes $E\{|r|^2_2\}$ (the expectation
of the square of $r$) using an interative algorithm where, in the
iteration $i$ computes
\begin{equation}
  h^{(i+1)} = h^{(i)} + \mu r^{(i)}{\mathbf m}[i],
\end{equation}
where
\begin{equation}
  r^{(i)} = {\mathbf s}[i] - \hat{\mathbf e}[i],
\end{equation}
and $\mu$ is the ``learning rate'' of the LMS algorithm.
